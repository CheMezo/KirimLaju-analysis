# KirimLaju-analysis

**About the Project**
This project analyzes logistics shipment data to understand service performance, shipment distribution, and shipping cost contributions across different delivery services.
Note: Kirimlaju is a simulated logistics dataset.

**Objectives**
- Analyze shipment volume by delivery service.
- Compare shipment volume and total shipping costs.
- Calculate the average shipping cost per shipment.
- Identify insights to support logistics resource allocation.

**Tools that I used**
- MySQL for data cleaning, data standardization and answering business question
- Power BI for dashboard visualization
